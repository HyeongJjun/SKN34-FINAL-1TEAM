- 비슷함 = 질문 ↔ 예시 질문 바이그램 TF-IDF 코사인 최댓값. 맞물림 = 카드 조각이 같은 질문의 키워드 검색 위 5개에 있음.
- 이건 **흉내**예요. 지금 예시 질문은 카드 열쇠로 쓴 것이 아니고 정답은 조각 단위예요. 결론은 두 가지만 가져가요: (1) 맞물림이 정밀도를 올린다, (2) 지금 예시 질문만으로는 카드 정밀도 0.9에 못 미친다 → 실제 질문 묶음에서 열쇠를 여러 개 만든 카드가 필요하다.
