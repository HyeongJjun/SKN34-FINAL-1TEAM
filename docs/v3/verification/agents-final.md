## 5. 결론

1. **안전은 확실해요.** 모든 판 · 모든 판정자에서 지어낸 숫자 · 업체 추천 · 하자 단정이 0이에요. held-out에서는 말한 문장이 모두 근거에 받쳐졌어요.
2. **처음 보는 질문을 덮는 힘은 약해요.** held-out에서 제대로 답한 비율은 8~10%, 일부라도 답한 비율은 22~28%예요. 나머지는 정직하게 '확인하지 못했어요'라고 답해요.
3. **dev 개선은 dev에 맞춰졌어요.** dev yes는 0.27에서 0.51로 올랐지만, held-out은 그만큼 오르지 않았어요. 빠진 주제를 채우는 방식은 넓게 퍼지지 않아요.
4. **막히는 곳은 '근거를 찾는 힘'이에요.** 답을 쓰는 힘이 아니에요. 그래서 다음은 아래 세 가지 중에서 골라야 해요(사용자 확인).
   - (a) 의미 검색: 로컬 임베딩 모델 내려받기(약 2GB), 또는 임베딩 API 키
   - (b) 공종마다 공공 자료를 크게 늘리기(공종당 100조각 이상)
   - (c) LLM 모드 키(근거 위에서 다듬기)
   - (a)와 (b)가 먼저예요. (c)는 근거가 있을 때만 도움이 돼요(E3-D).
