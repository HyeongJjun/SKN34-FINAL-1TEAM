## 5. CI에 넣는 계획 (이번에는 `ci.yml`을 고치지 않았어요)

- 새 일 `e2e`(backend · frontend 일 뒤, ubuntu): 서비스 컨테이너 `pgvector/pgvector:pg17` · `redis:7`.
- 순서: `uv sync` → `alembic upgrade head`(DB `mitjip_v3`) → `APP_ENV=test python -m app.demo`(시연 데이터) → `pnpm install --frozen-lockfile` → `npx playwright install --with-deps chromium`(CI만 내려받음) → `CI=1 pnpm exec playwright test` → 실패하면 `frontend/e2e/.out/`(html 보고서 · 스크린샷 · 추적)를 artifact로.
- 바꿀 것: `e2e/tools/db.sh`가 `docker exec` 대신 `psql` · `createdb`를 서비스 주소(PGHOST)로 쓰게(`E2E_DB=service`), webServer API 명령은 `run-api-copy.sh` 대신 `uv run uvicorn`(DATABASE_URL = `mitjip_v3_e2e`), 화면은 `pnpm build` + `pnpm start`. `channel`은 CI에서 비워요(이미 그렇게 둠).
- 시간: 지금 로컬 한 줄 실행 5.4분(최종) + 빌드 · 시드. PR마다가 길면 `main` 병합 · 수동 실행만.

## 6. 산출물 · 돌리는 법

- 돌리기(`frontend`): `pnpm exec playwright test`(폰 · 웹), 하나만: `pnpm exec playwright test e2e/j05-visit-dates.spec.ts --project=web`. 떠 있는 8018 · 3108 서버가 있으면 다시 써요(`reuseExistingServer`), 없으면 띄우고 끝나면 꺼요.
