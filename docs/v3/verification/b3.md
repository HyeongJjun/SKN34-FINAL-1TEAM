## 5. 예시 → 실제 API

- 바꾸는 곳은 `lib/api/{vendor,admin}.ts` 안뿐이에요. `MOCK`은 `NODE_ENV !== "production" && NEXT_PUBLIC_MJ_V3_MOCK === "1"`이라 운영 빌드는 늘 실제 API예요. 예시 데이터는 `Schemas[...]` 타입(B1a 0단계 `schema.d.ts`)으로 만들어 타입 검사를 지나요.
- 읽기는 contract.md 3장 경로를 그대로 불러요. 지금 동작하는 경로: `/vendor/application` · `/vendor/profile`(v3 칸 저장됨) · `/vendor/visits` · `/vendor/visits/{id}`(v3 칸은 기본값) · `…/quote` · `/vendor/jobs/{id}` · `/vendor/prices`(`v3`는 0단계에 비어 있음) · `/admin/vendors*` · `/regions`.
- 0단계 501(B1a 1단계 · B1b가 켜면 화면은 고칠 것 없음): `tab=sched` · `sort` · `/vendor/schedule` · `/vendor/review-links` · `/vendor/reviews` · `/vendor/jobs/{id}/log` · 기간 답하기 · 수락 · 제안 · 링크 확인 · `/admin/reports*` · `/admin/members*`. 실제 모드에서 이 화면은 지금 오류 화면이 돼요(빈 화면으로 속이지 않아요). 처음 할 일(V02)은 부분 실패를 '아직 안 함'으로 봐요.
- 쓰기는 `components/pro/send.ts` → `call()`: 경로 id는 `encodeURIComponent`, 두 번 눌러도 한 번만 돼야 하는 쓰기(단가 확인 · 기간 답하기 · 수락 · 제안 · 견적서 · 공사 날짜 · 추가 금액 · 공사 끝 · 답글 · 심사 · 처리 · 정지 · 가입 · 다시 신청)는 `Idempotency-Key`(B7).
- 실제 API로 돌려 본 것: 없음.
