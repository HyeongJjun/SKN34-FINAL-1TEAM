## 3. 실시간(줄기) 확인

로그인한 고객으로 3107(예시 끔)의 `/notifications`를 열고, 가짜 줄기 서버가 연결마다 `ready` 뒤 이벤트 3개(notif · msg, `id` 붙임)를 보내고 끊게 했어요. 서버 기록은 연결마다 `Last-Event-ID`와 쿠키 유무를 남겨요.

| 본 것 | 결과 |
| --- | --- |
| 첫 연결 | `Last-Event-ID` 없음 · 쿠키 있음. notif `unread: 3` → 종 '알림, 새 알림 3개' → `unread: 5` → '새 알림 5개' |
| 서버가 끊음 | 2초 뒤(`retry: 2000`) 브라우저가 다시 이음: `Last-Event-ID` '3' → '6' → '9' → '12', 다음 번호부터 받음 |
| 로그인 뒤 401(ready를 본 뒤) | 5초 뒤 손으로 다시 엶(뒤로 미루기 5 · 10 · 30 · 60초) |
| 새로 연 화면에서 처음부터 401 | 0초 · +5초 · +10초 세 번 뒤 멈춤(+30초 시도 없음) |
| 멈춘 뒤 `online` 이벤트 | 다시 엶 → 종 '새 알림 3개' |
| 알림 화면 '모두 읽음' | `useLive().setUnread(0)` → 머리 종 '알림' · 탭 바 숫자 없음 |
| msg 이벤트 → 채팅 화면이 새 글을 읽는지 | 못 봄(실제 `/threads`가 501, 예시 모드는 줄기를 열지 않아요) |
