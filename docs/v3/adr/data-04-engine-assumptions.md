- 상태: 사용자 확인 필요 (값은 바꾸지 않았어요)
- 날짜: 2026-11-18 · 쓴 역할: 데이터 수집(B6)
- 관련 화면 · 이야기: C07 표준견적서, C11 · D02 가견적, 공정표(품 · 일수) · 관련 코드: `backend/app/refprice/book.py`(`DOBAE_2026H2`), `backend/app/refprice/house.py`(`supply_per_exclusive`), `backend/app/calc/dobae.py`(B1a), `data/v3/scripts/engine_impact.py`

## 배경

표준견적서 계산의 가정값 4개가 이번에 모은 자료와 달라요. 바꾸면 고객이 보는 금액 · 가견적 · 품이 바뀌니 사용자가 정해요. 이번에는 리드 지시대로 값을 그대로 두고 차이와 금액 영향만 적어요.

## 고른 것과 이유

- 고른 안: 없음. 이번에는 값을 바꾸지 않아요. 아래 넷을 사용자가 정해 주세요.
  1. 도배 면적 계수 2.5 → 2.2 · 천장 35%로 바꿀까요? 자료 두 갈래(평면도 계산 · 실견적 롤 수)가 서로 맞고 시장 계산도 2.24를 써요. 다만 표준견적서를 넉넉하게 잡으려고 일부러 2.5로 둔 것이면 그대로 둬요.
  2. 전용 → 공급 1.2 → 1.315(또는 면적대별 표)로 바꿀까요? 면적대마다 1.223~1.376이라 한 값보다 면적대별 표가 자료에 맞아요.
  3. 떼내기를 품셈 값(벽 2,702 · 천장 3,507원/㎡)으로 맞출까요? 고객 합계에는 영향이 없어요. 도배공 2026.9.1 노임(229,833원)은 저장소 PDF 전처리본으로만 확인했어요.
  4. 천장 품 × 1.3을 품셈 값(0.0306)으로 바꿀까요? 34평 가견적 인건비가 0.5품(150,000원) 줄어요.
- 바꾸면 산식 버전을 올려요. 이미 만든 견적은 만든 때의 산식 · 단가 버전을 그대로 써요(AGENTS.md 3장).
