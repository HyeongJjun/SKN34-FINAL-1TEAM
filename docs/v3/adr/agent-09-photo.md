# agent-09 AI 칸 사진 읽기 (#181 2단계)

- 상태: **제안** (보관 기간 · 국외 이전 고지 문구는 팀 · 법무 확인 필요)
- 날짜: 2026-11-24
- 관련: #181, PR #184(1단계: 업체 채팅으로 잇기), security.md FI-02 · FI-05 · LM-04, security-01(채팅 보관)

## 문제

- 고객이 재재에게 집 사진을 보여 주고 물을 수 없음("이 곰팡이 도배로 되나요?")
- 사진에는 얼굴 · 동호수 · 택배 송장이 찍힐 수 있고, 사진 해석은 유료 LLM 호출임
- AI 칸 규칙: 금액 · 기간은 계산 엔진만, 답은 자료 근거, 하자 판정은 하지 않음

## 고른 안

| 항목 | 정한 것 |
| --- | --- |
| 받기 | 기존 `POST /files`(kind=`photo`, 고객만)로 먼저 올리고 `POST /ai/turns`에 `file_ids`(3장까지)만 보냄. 위치 · 기기 정보는 올릴 때 서버가 지움(FI-02). migration 없음 |
| 권한 | 내가 올린 공간 사진만. 남의 파일 · 다른 종류 · 없는 파일은 똑같이 404 |
| 상한 | 한 번에 3장, 사용자별 하루 20장(`agent/v3/photo.py`). 로컬 환경은 세지 않음 |
| 읽기 | LLM 모드에서만. 긴 변 1024px JPEG로 줄인 사본을 보냄. 고객이 쓴 글은 사진 판독 호출에 넣지 않음 |
| 읽는 모양 | 모델은 문장을 쓰지 않음. 정해 둔 목록에서 증상 7종 · 위치 6종 · 집 안 사진 여부 · 사람/글자 보임 여부만 고름(`PhotoSeen`). 사진 속 글자 · 사람을 받을 칸이 없음 |
| 답 | 증상을 지금 AI 칸이 자료로 답하는 질문으로 바꿔 기존 한 턴에 넘김(곰팡이 · 들뜸 · 이음매 · 구멍/금). 자료 없는 증상(결로 · 벗겨짐 · 얼룩)은 본 것 + '실측 때 업체 확인'만 |
| 화면 글 | '사진에서 본 것'은 정해 둔 글 + 목록 낱말만. 답 위에 따로 보임(`AiAnswer.photo`) |
| 무료 모드 | 읽지 않음. "지금은 재재가 사진을 읽지 못해요. 사진은 업체와 채팅에서 보내 주세요." |
| 실패 | "사진을 읽지 못했어요" + 글 질문만 답함. 꾸며 낸 설명으로 채우지 않음 |
| 개인정보 안내 | 올리기 전 "얼굴 · 동 · 호수 · 택배 송장은 가리고 올려 주세요". 자동 가림은 만들지 않음. 사람/글자가 보이면 다음부터 가려 달라고 알림 |
| 보관 | 사진 파일은 올린 사람 것으로 남고 탈퇴하면 지움(기존 탈퇴 처리). 대화에는 "(사진 n장)"만 남김 |
| LLM 제공사 | 학습에 쓰지 않는 API 설정으로만 보냄. 국외 이전은 처리방침 · AI 칸 고지에 적어야 함 |

## 고르지 않은 안

- 모델이 사진 설명 문장을 직접 씀: 사진 속 글자 · 지시문이 답으로 새거나 금액 · 판정을 지어낼 길이 생김
- 사진 속 얼굴 · 글자 자동 가림: 오탐 · 미탐과 구현 비용이 큼. 안내 + 받을 칸 없는 스키마로 대신함
- AI 사진 전용 파일 종류: CHECK 제약 migration이 필요. 고객 공간 사진과 같은 규칙이라 `photo`를 그대로 씀

## 하지 않는 것

- 금액 · 기간 · 하자 판정, 사람 식별, 사진 속 글자 읽기
- 손님(로그인 전) · 업체 화면의 사진 질문
