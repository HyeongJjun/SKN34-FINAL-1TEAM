# agent-02 무료 모드 답 방식: 검증된 답 카드 → 조각 문장 뽑기 → 정직한 '모름' + 계산 엔진 상자 · 정해 둔 글

- 상태: 고름
- 날짜: 2026-11-18 · 쓴 역할: 에이전트 설계
- 관련 화면 · 이야기: C09 · D01 '자동 답변', C58 로그인 전 질문 칩, J1 · 관련 코드: `backend/app/agent/llm.py`(`CHAT_STUB_TEXT`), `backend/app/knowledge/*`, `backend/app/v2/guard.py`, 설계 [agents.md](../agents.md) 10절

## 배경

v3는 유료 키 없이 모두 돌아야 하고(지시문 1 · 3장), 지금 `LLM_LIVE=false`에서는 어떤 질문에도 정해 둔 한 문장만 돌려줘요. 생성 모델 없이 공종별 · 지식 질문을 넓게, 틀리지 않게 답할 방식을 정해야 해요.

## 고른 것과 이유

- 고른 안: **C**
- 이유
  1. LLM은 이해에만, 업무는 정해진 흐름이 결정적으로, 응답은 템플릿이 기본인 방식이 이미 쓰여요 [1]. 믿집 무료 모드의 '이해'는 규칙 + 학습 분류기, '답'은 카드 · 정해 둔 글이에요.
  2. 고객 상담 봇의 지시 끼워 넣기 방어로 '허용 목록에서 고르기(action-selector)'가 제시돼 있어요 [2]. 카드 고르기가 바로 그 모양이라 고객 글이 답 내용을 바꿀 길이 없어요.
  3. 측정: 예시 질문(고객 말투 열쇠)을 빼면 검색 hit@5가 0.665 → 0.539(dev)로 떨어졌어요. 카드에 열쇠 질문을 여러 개 다는 근거예요.
  4. 사전 실험: 예시 질문을 카드 열쇠로 흉내 냈을 때, 비슷함만 쓰면 근거 맞음 0.470(기준 0.4)이었고 '검색 맞물림'을 더하면 0.679로 올랐어요. 받아들이기 규칙에 맞물림을 넣어요. 다만 흉내 수준으로는 0.9에 못 미쳐 실제 질문 묶음으로 만든 카드가 필요해요.
  5. 근거를 줘도 LLM이 근거 없는 내용을 넣고 그 감지도 어렵다는 측정 [6][5] → 미리 쓰고 검증한 글을 내보내는 편이 무료 모드에 맞아요.
  6. 카드 문장은 근거를 풀어 쓴 새 글이라 원문을 길게 옮기지 않아요. 추출식은 공공 자료는 그대로, 제조사 · 경험담은 짧게, 책은 허락 전까지 안 보여요.
