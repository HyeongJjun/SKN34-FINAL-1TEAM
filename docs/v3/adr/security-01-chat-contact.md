# security-01 채팅 속 연락처 가림 · 보관 방식

- 상태: **사용자 확인 필요**(보관 기간 부분). 채팅 본문을 가리지 않는 것은 9판 D05 A를 그대로 따라요
- 날짜: 2026-11-18 · 쓴 역할: 보안 담당
- 관련 화면 · 이야기: C24 chat_list · C25 chat · C26 plus · C53 withdraw · C55 legal · C62 chat_warn · D05 d_chat · V09 v_chat · V19 v_chats · A02 a_report, J8 · J20, 팀 확인 7 · 11
- 관련 코드: `backend/app/v2/guard.py` `mask` · `backend/app/agent/intent.py` `clean` · `backend/app/visit/service.py` `contact_visible` · `backend/app/notify/service.py`

## 배경

- 11-18 결정으로 + 메뉴의 '주소와 번호'를 뺐어요. 고객이 동 · 호 · 연락처를 채팅에 직접 쓰고, 업체는 요청 · 작업함에서 구 · 동까지만 봐요(D04 A).
- 채팅 번호는 가리지 않아요. 믿집 밖 거래 권유에만 고객 화면에 주의 줄을 한 줄 붙여요(D05 A).
- 그런데 보낸 연락처에 기간 제한이 없는 S18 B는 개인정보 보호법과 부딪혀요(팀 확인 7).
  - 제17조②4: 제공받는 자의 보유 · 이용 기간을 알려야 해요.
  - 제21조: 목적을 이루면 지체 없이 파기해야 해요.
  - 탈퇴 화면(C53)의 '이미 보낸 메시지는 그 업체 채팅에 남아요'도 같은 문제예요.
- 채팅 글이 알림 · 관리자 화면 · 로그 · LLM으로 복사되면 번호가 더 퍼져요. 실시간 채팅을 만들기 전에 정해야 해요.

## 고른 것과 이유

- 고른 안: **D**. C 부분(사본 가림)은 D05 A와 부딪히지 않아서 바로 만들어요. 기한 뒤 가림 · 분리 보관 · 탈퇴 즉시 가림은 사용자 확인 뒤에 만들어요.
- 세부
  1. 채팅 화면 본문은 가리지 않아요(D05 A).
  2. 주의 줄(무료 모드 규칙): 계좌 꼴(은행 이름 근처 숫자 10~14자리)이나 '현금 · 입금 · 선입금 · 계약은 따로 · 직거래 · 수수료 없이 · 카톡 아이디 · 오픈채팅 · 외부 링크' 낱말이 있으면 고객 화면에만 한 줄을 붙여요. 막지 않아요. 검사 결과는 원문 없이 숫자만 기록해요. 국내 중고거래 플랫폼도 채팅 속 계좌 · 전화번호를 감지해 경고해요 [6].
  3. 사본 가림: 알림 글은 '새 메시지가 왔어요 · 업체 이름'만 쓰고 본문을 넣지 않아요. 관리자 신고 목록 · 로그 · LLM 입력 · 기록 내보내기는 가림 모듈(`security.md` 8.5)을 써요. 관리자 신고 자세히에서만 원문을 보고, 그때 열람 기록을 남겨요.
  4. 기한 뒤 가림: worker 정리 일이 매일 기한이 지난 대화방을 '가림 상태'로 바꾸고, 업체 응답에는 가린 글을 내려줘요. 원문은 분리된 표로 옮겨요(제21조③ 분리 저장) [2].
  5. 처리방침 '업체에 주는 정보'의 '업체가 보는 기간: 정할 것'(C55)을 이 기한으로 채우고, 채팅 첫 화면에 한 줄 알려요.
- 이유
  - 받는 자 보유 기간 고지 · 지체 없는 파기 · 분리 보관은 법 조문이에요 [1] [2].
  - 분쟁 원문 3년은 중개자의 분쟁 기록 보존 기간과 맞춰요(중개자 여부는 팀 확인 9) [3].
  - 로그 · 사본에서 민감 값을 가리는 것은 ASVS 16.2.5 · 14.2.6이에요 [4].
  - LLM으로 가는 개인정보를 줄이는 것은 LLM02예요 [7].
  - '공사 끝 + 1년'은 팀이 v2에서 이미 쓴 연락처 공개 기한이에요(`docs/v3/research/00-codebase.md`).

## 다시 볼 조건

- 사용자가 S18 B(기한 없음)를 그대로 두기로 하면: 법무가 처리방침에 '업체가 보는 기간: 제한 없음'을 써도 되는지 먼저 확인해요.
