# data-02 공휴일 자료 기준과 해마다 갱신하는 방법

- 상태: 고름 · 저장소 반영함(2026-11-18 B6: `holidays.py`에 평일 4일, `HOLIDAYS_EXTRA` 비움) · 이름 맞추기는 사용자 확인 필요
- 날짜: 2026-11-18 · 쓴 역할: 데이터 수집
- 관련 화면 · 이야기: 공정표 · 실측 일정(J5) · 공사 날짜(J7) · 관련 코드: `backend/app/refprice/holidays.py`, `backend/app/refprice/v2_ref.py`(HOLIDAYS_EXTRA), `backend/app/schedule/service.py`, `data/v3/scripts/holidays.py`

## 배경

공정표는 주말과 공휴일을 건너뛰어요. 2026-04-28 '관공서의 공휴일에 관한 규정' 개정으로 노동절(5/1)과 제헌절(7/17)이 공휴일이 되고 대체공휴일 대상이 됐어요. 2027년도 월력요항은 2026-06-29 우주항공청이 발표했어요.

지금 저장소는 두 곳에 나뉘어 있어요.
- `holidays.py`(HOLIDAYS): 노동절 · 제헌절이 없어요.
- `v2_ref.py`(HOLIDAYS_EXTRA): 4일이 따로 있어요.

`schedule/service.py`의 `days_off`는 `holidays.py`만 읽어요. 그래서 공정표가 2027-05-03(노동절 대체) · 2027-07-19(제헌절 대체)를 일하는 날로 세요. v2 화면은 두 목록을 합쳐 보여 줘서 화면과 공정표가 달라요.

## 대안

## 고른 것과 이유

- 고른 안: **B**. `data/v3/holidays/holidays_2026_2027.csv`(46일, 줄마다 근거 · 출처) + `diff.json`(저장소와 차이).
- 이유
  1. 노동절 · 제헌절처럼 규정이 바뀐 해에는 공개 페이지도 늦게 고쳐져요. 천문연 2026 페이지는 아직 노동절을 기념일(근로자의 날)로만 적고 '공식 발표 자료가 아닙니다'라고 밝혀요 [근거 1]. 그래서 인사처 보도 [근거 3]와 월력요항 보도 [근거 4]를 같이 봐야 해요.
  2. 키 없이 돌고, 출처가 줄마다 남아요(지시문 3.1).
  3. 해마다 6월 말 월력요항이 나오면 다음 해 줄만 더하면 돼요.
- 저장소 반영(2026-11-18, B6)
  - `holidays.py`에 평일 4일(2026-05-01 노동절 · 2026-07-17 제헌절 · 2027-05-03 노동절 대체공휴일 · 2027-07-19 제헌절 대체공휴일)을 출처 주석과 함께 더하고 `HOLIDAYS_EXTRA`를 빈 표로 남겼어요(v2 화면이 이름을 합쳐 써요). 이제 공정표와 v2 화면이 같은 목록을 써요.
  - 토요일인 2027-05-01 · 2027-07-17은 더하지 않았어요. `holidays.py`는 평일만 적는 관례라서요(예외는 원래 있던 2026-09-26 하나). 주말은 어차피 쉬는 날로 세요.
  - 테스트: `backend/tests/test_v3_refprice_holidays.py`(공식 평일 공휴일 목록과 같음 · 2027-05 · 07 대체공휴일을 건너뜀).
  - 남은 것: 이름을 공식 이름(1월 1일 · 기독탄신일 · 대체공휴일(○○))으로 맞출지는 사용자 확인 필요예요. 지금 '신정' · '성탄절'도 뜻은 같아요.
