# 공종 에이전트 템플릿

이 폴더를 `specialists/` 아래에 복사하고, 이름을 공종 코드로 바꿔요. 코드는 영문 소문자로 시작하고 소문자·숫자·밑줄만 사용해요. 원본 `_template`은 자동 등록에서 제외돼요.

| 파일 | 복사한 뒤 할 일 |
| --- | --- |
| `spec.py` | 새 공종이라면 표시 이름, 질문에서 공종을 찾을 단어, 자료의 공종 태그, 공정 순서를 채워요. 공종 코드는 폴더명에서 가져와요. 목공처럼 기존 공종 설정을 그대로 쓸 경우에는 이 파일을 빼고 기존 공종 코드로 폴더를 만들어요. |
| `retrieval.py` | 기본 키워드 검색으로 시작해요. 검색어 보강, 후보 정렬, 벡터 후보 결합 등은 필요할 때 이 파일에서 개발해요. 벡터 검색을 붙일 때는 [공종 에이전트 추가 방법](../../../../../../docs/v3/trade-specialists.md#공종-에이전트-추가-방법)을 참고해요. |
| `prompt_v1.md` | LLM 모드에서 공통 지침에 추가할 공종별 답변 기준을 적어요. |
| `agent.py` | 기본 공종 답변 흐름을 호출해요. 공종 전용 처리 순서가 필요할 때 수정해요. |

선택 파일인 `retrieval.py`, `prompt_v1.md`, `agent.py`를 빼면 해당 항목은 공통 동작을 사용해요. 복사와 설정을 마치고 서버를 다시 시작한 뒤, 실제 공종 질문으로 분류와 답변 근거를 확인해요. 검색할 자료는 활성 버전에 적재되어 있어야 해요.
