# 초보 고객 질문 묶음 `beginner_web`

## 목적

- 기존 질문 은행(`data/v3/questions/*.jsonl`, 13공종 493문항)은 difficulty 1이 142개, intent 업체 16 · 기간 27 · 가격 45로 아주 기초적인 질문이 적어요.
- 인테리어를 잘 모르는 고객(처음 고치는 사람, 세입자 · 집주인, 부모님 집을 맡은 자녀, 고령 고객)이 실제로 묻는 쉬운 질문 227개를 더해 그 빈 곳을 채워요.
- 카드 열쇠(`keys`) 후보, 입구 분류 · 답 카드 평가에 기존 은행과 같이 써요.

- checked_at: 모두 `2026-11-19`
- split: id를 정렬한 순서로 3개마다 하나를 heldout(dev 152 : heldout 75). 기존 은행은 글자 sha1 % 3 규칙이라 규칙이 달라요.
- intent에 `관리사무소`를 5문항 썼어요(신고 · 동의서 · 엘리베이터 사용료 · 이웃 공사 불편 · 복도 작업). 기존 은행은 같은 주제를 `순서` · `기간`으로 붙였으니, 9개 값만 받는 코드라면 `관리사무소 → 순서`로 읽으면 돼요.

## 모은 방법

- 웹 검색(WebSearch) 42회. 검색 결과가 업체 블로그 위주라, 질문 게시판은 각 사이트의 게시판 검색 쪽을 직접 열어 제목을 모으고 글을 열어 질문을 확인했어요.
- 직접 연 페이지는 약 330쪽이에요(대략값).
  - 게시판 목록 · 검색 약 57쪽: 82쿡 23 · 디시 14 · 생활법령 백문백답 목록 13 · 클리앙 5 · 소비자24 2
  - 질문 글 약 260쪽: 82쿡 약 142 · 디시 76 · 클리앙 31 · 월급쟁이부자들 6 · 로톡 2 · 세이프홈즈 1 · 숨고 질문 1
  - 안내 · 블로그 · 업체 소개 · 공공 문답 14쪽: 숨고 블로그 6 · 숨고 업체 소개 3 · 생활법령 문답 3 · 비즈폼 1 · 한샘 1
- 글은 옮기지 않았어요. 출처 글이 묻는 뜻만 살려 초보 고객 말투로 새로 썼어요(한 문장, 80자 이하, 해요체 의문문).
  - 반말 · 거친 말투(디시)도 해요체로 맞췄어요.
  - 용어를 잘못 쓰거나 막연하게 묻는 질문도 섞었어요. 예: "실크 벽지가 뭐예요, 비단으로 만든 거예요?", "벽지 밑에 하얀 천 같은 거…", "두꺼비집", "육가", "도배는 평당 얼마예요?"
- 개인정보 · 업체명 · 상표명 · 아파트 이름 · 동호수 · 전화번호 · 특정 업체 견적 금액은 넣지 않았어요.
- 한 출처에서 가져온 질문은 최대 3개예요.
- source_check: 227개 모두 `opened`(연 페이지에 같은 뜻의 질문이 있음).
  - 디시 글 4개(no 4151 · 4036 · 7664 · 3871)는 본문이 안 읽혀 제목만 확인했어요. 질문은 제목에 있어요.
  - 숨고 `questions/2029`의 질문 2개는 그 페이지에 보이는 관련 질문 제목에서 가져왔어요.
- 다 쓴 뒤 질문마다 출처 글과 다시 대조했어요. 질문이 없는 글(경험담 · 조언)이나 그 질문을 묻지 않은 글에서 온 5개, 기존과 뜻이 겹치는 2개를 뺐고, 10개는 출처의 실제 질문에 맞게 고쳐 썼어요.
- 유료 API(LLM 키)는 쓰지 않았어요.

## 빼거나 못 한 것

- 기존 질문과 뜻이 같아서 뺀 후보 약 50개
  - 예: 벽지 대신 페인트 단점, 실크 · 합지 구분법, 장판 덧방, 평수별 도배 총액, 도배 A/S, 몰딩만 교체, 장판 굽돌이, 욕실 덧방, 콘센트 추가, 입주 청소 꼭 해야 하는지, 예산 잡기, 견적서를 안 주는 업체, 주말 공사 소음, 이사 · 업체 추천
- 평가 세트와 글자가 같아서 뺀 2개: `evaluation/rag/questions_300.jsonl`의 xd008(타일 벽 위 실크 벽지) · xm005(걸레받이 높이)
- 출처에 질문이 없거나(경험담 · 조언) 상표 · 모델 중심이라 뺀 후보 약 15개
- 막혀서 못 쓴 곳: 네이버 지식iN(가져오기 막힘), 오늘의집 질문과답변(403), 뽐뿌(403 · 글자 깨짐), 숨고 질문 쪽 번호 훑기(403, WebFetch로 1쪽만 열림), 소비자24 피해구제 목록(검색어가 안 걸러져 새 사례를 못 찾음)
- 공공 안내(public_faq)는 3문항뿐이에요. 공공 FAQ가 검색에 거의 안 걸렸어요.
- 출처가 커뮤니티(질문의 88%)에 몰려 있어요. 82쿡은 중년 · 주부, 디시는 젊은 남성 말투가 많아요.
- 그 밖 공종은 창호 15 말고는 한 자리 수예요(설비 · 필름 · 도장 1개).
- 기간 질문은 10개로 다른 intent보다 적어요.
- 정답 카드(gold)는 달지 않았어요. 질문 은행용이에요.
- 뜻이 같은지는 수집 담당 판단이라 틀린 것이 있을 수 있어요.

## 쓰는 법

```python
import glob, json
rows = []
for f in glob.glob("data/v3/questions/*.jsonl") + ["data/v3/questions/beginner_web/questions.jsonl"]:
    rows += [json.loads(l) for l in open(f, encoding="utf-8") if l.strip()]
dev = [r for r in rows if r["split"] == "dev"]          # 튜닝 · 카드 열쇠
heldout = [r for r in rows if r["split"] == "heldout"]  # 마지막 확인에만
beginner = [r for r in rows if r.get("level") == "beginner"]
```

- 기존 행에는 `level` · `source_type` 칸이 없어요. `r.get()`으로 읽어요.
- `관리사무소` intent를 모르는 코드는 `순서`로 바꿔 읽어요.
- 생성 · 검사 스크립트는 저장소에 넣지 않았어요(기존 은행과 같은 방식). 다시 모을 때는 같은 칸으로 줄을 더하고 위 검사 항목을 다시 돌려요.
